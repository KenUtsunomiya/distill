# distill

A daily Claude Code routine collects articles on work-related themes and delivers them as GitHub Issues. See [docs/distill-concept.md](docs/distill-concept.md) and [docs/routine-design.md](docs/routine-design.md).

To read and mark the articles, use the reader page in [app/](app/README.md). It runs on Cloudflare Workers with GitHub sign-in ([design](docs/reader-design.md)).
