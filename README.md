# distill

A daily Claude Code routine collects articles on work-related themes and delivers them as GitHub Issues. See [docs/distill-concept.md](docs/distill-concept.md) and [docs/routine-design.md](docs/routine-design.md).

## Reader

**https://distill-reader.distill-reader.workers.dev**

Read and mark the articles here: a heart for the ones to read, a check once read. Sign-in is with GitHub and limited to my account. The code is in [app/](app/README.md), and the design in [docs/reader-design.md](docs/reader-design.md).
